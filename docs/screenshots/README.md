# Screenshots

Add these images here (same filenames as referenced in the root README),
then they'll render automatically on GitHub:

| Filename | What to capture |
|---|---|
| `home.png` | The home page — hero + featured listings, at localhost:5173/ |
| `listings.png` | The Listings page with the filter bar and a few photo-filled cards visible, at localhost:5173/listings |
| `detail.png` | A single listing detail page with a real photo, e.g. localhost:5173/listings/MW-014 |
| `dashboard.png` | The agent Dashboard after logging in, showing the inventory table |

Tips for good screenshots:
- Use your browser's device toolbar or just resize the window to a clean
  1440×900-ish size before capturing, so GitHub renders them consistently.
- Crop out browser chrome (address bar, other tabs) if you can — the
  `Win + Shift + S` snipping tool on Windows or `Cmd + Shift + 4` on Mac
  both work well for this.
- Run `fetch_photos.py` first so the listings/detail screenshots show real
  photos instead of the blueprint diagrams.
